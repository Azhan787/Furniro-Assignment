# Furniro — E-Commerce Website

A modern, pixel-perfect recreation of the **Furniro E-Commerce Website**, developed from the official Figma design. This project focuses on clean semantic HTML, responsive CSS, and lightweight Vanilla JavaScript to deliver a smooth and interactive shopping experience.

## 📌 Project Overview

**Furniro** is a fully responsive furniture e-commerce frontend consisting of **9 main pages** and reusable UI components, including a slide-out cart drawer.

The project is built without any frontend frameworks, keeping the implementation lightweight and focused on core web technologies.

### ✨ Highlights

* Pixel-perfect UI implementation based on Figma
* Fully responsive design for desktop, tablet, and mobile
* Semantic HTML5 structure
* Modern CSS3 layout techniques
* Reusable and modular JavaScript functionality
* Interactive product filtering and sorting
* Product comparison interface
* Shopping cart and cart drawer
* Checkout and billing form UI
* Contact form validation
* Blog search and category sections
* Font Awesome icons
* Clean and organized project structure

## 🛠️ Tech Stack

| Technology                | Purpose                                                 |
| ------------------------- | ------------------------------------------------------- |
| **HTML5**                 | Semantic and accessible page structure                  |
| **CSS3**                  | Responsive layouts, styling, animations, and components |
| **JavaScript**            | DOM manipulation and interactive functionality          |
| **Flexbox**               | One-dimensional responsive layouts                      |
| **CSS Grid**              | Product grids and complex layouts                       |
| **CSS Custom Properties** | Reusable design variables                               |
| **Font Awesome**          | Icons and UI elements                                   |

### HTML5

Semantic elements such as:

```html
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

are used to maintain a structured and accessible document hierarchy.

### CSS3

The styling system makes use of:

* Flexbox
* CSS Grid
* Custom Properties
* Responsive Media Queries
* Transitions and animations
* Component-based styling
* BEM-inspired naming conventions

### JavaScript

Vanilla JavaScript is used for:

* DOM manipulation
* Product filtering
* Product sorting
* Cart interactions
* Slide-out cart drawer
* Form validation
* Search functionality
* UI interactions
* Quantity controls

## 🚀 Getting Started

Since Furniro is built with plain HTML, CSS, and JavaScript, there is no build process or package installation required.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/furniro.git
```

### 2. Navigate to the project

```bash
cd furniro
```

### 3. Run the project

You can open `index.html` directly in your browser.

For the best development experience, use **VS Code Live Server** or another local development server.
